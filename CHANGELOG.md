### Security

- `--from`/`--to` were passed straight to `git log`/`git rev-parse`, so a value such as
  `--output=<file>` made git write an arbitrary file. Revisions starting with `-` are now
  rejected and all revisions follow `--end-of-options`.
- `git log` is run with `log.showSignature=false`, so repository config cannot make it run
  `gpg.program`.

### Fixed

- The CLI did nothing when run through a symlinked npm bin (`npm link`, `node_modules/.bin`).

### Documentation

- README install section: the npm `changelog-forge` package is an unrelated project.
- CI workflow runs with `permissions: contents: read`.
